# ゲーム画面とコントローラ操作

`MasterController.Start` が `GameFlowController` を追加し、同じ BattleGround シーンで「タイトル → 難易度（ひとり用） → キャラクター選択 → ゲーム」を切り替えます。スマホ・無線リモコン・USBの接続は画面を切り替えても維持します。

- タイトルは「ひとりで遊ぶ」（100人に挑戦）、「ふたりで対戦」（先に3本とる）、「フリーモード」の3項目です。どちらのコントローラでも選択・決定できます。
- ひとり用はキャラ選択の前にイージー／ノーマルを選びます。ノーマルは通常の攻撃速度、イージーは敵の交代待ち1.5倍・攻撃準備1.5倍・斬りの時間1.35倍です。人数・敵の接近速度・体力は同じです。再戦で難易度を維持します。
- キャラクター選択は「キャラクター・色・スタート・もどる／プレビュー」の4段です。最下段で左に振ると「もどる」、右に振ると「プレビュー」を選び、ガードで決定します。ひとり用ではP1とP2が同じ選択パネルを操作します。対戦・フリーモードはそれぞれのパネルを独立して操作し、両方のスタートで進みます。
- 選択枠と決定済みの値は別に保持します。左右の操作は枠だけを動かし、ガードを押したときにその段の値を決定して次の段へ進みます。マウスのクリックも値を決定します。「スタート」の決定時は選択中のキャラクター・色を両方反映します。必要人数のスタートが揃う前なら方向操作で準備を解除して選び直せます。ひとり用は1人、対戦・フリーは2人の準備完了でそのまま開始します。
- 振った方向の角速度が360°/秒を超えると、その方向に選択枠が1項目移動します。360°/秒ちょうどでは移動しません。2026-10-08の再指定により、端末の絶対姿勢を使って固定のメニュー座標系に変換し、スマホの画面が上向きでも左に振れば左、左向きでも振り上げれば上へ移動するようにしました。スマホで保存した軸の入れ替え・反転はローカル軸にだけ適用し、ワールド座標系を初期設定の基準に固定するため、メニューの上下左右は変わりません。キャラクター段から下へ振ると色の段へ、右へ振ると次のキャラクターへ移動します。剣モデルの向きや正面合わせ時の傾きには依存しません。斜めの動きは速度の大きい方向を採用します。360°/秒を超えている間は連続移動せず、360°/秒以下になったら次の操作を受け付けます。戻り動作を区別する処理や元の姿勢へ戻す条件はなく、ゆっくり戻す動きは通常のしきい値だけで対象外になります。ジャイロが有効ならその値を使い、ジャイロ値を送らないリモコンは端末のサンプル時刻と絶対姿勢差分から角速度を求めます。画面遷移・入力源の変更・正面合わせ・古い姿勢の失効では入力履歴をリセットします。ガードを押している間は振る操作による選択を受け付けません。
- ガードは押した瞬間だけ決定に使います。押しっぱなしで次の画面も決定されることはありません。キーボードはP1がWASD・左Shift、P2が矢印・右Shiftで、スマホ・リモコンと併用できます。
- タイトル・難易度・結果画面はP1とP2が同じ選択を操作します。結果画面の「もう一度・モードを選ぶ・キャラクターを選ぶ」は剣・ガードでも操作できます。`ReturnToModes()` と `ReturnToCharacters()` が結果ボタンからの移動先です。
- 2026-10-09の指定により、リセットの短押しはメニュー・プレビュー・一時停止・結果を含む全画面で、押したコントローラの正面合わせに統一しました。画面を戻す場合は「もどる」を選びます。難易度はノーマルから下で「もどる」を選べます。0.5秒以上の長押しはプレビューでは選択画面へ戻り、それ以外の画面では一時停止を開閉し、離したときの短押しは発生しません。新しいスマホ・USB送信側は押下状態を送り、0.5秒未満で離したときだけリセット番号を増やします。押下状態を送らない旧ファームウェアでは番号の変化を短押しとして扱います。
- Escでも一時停止を開閉できます。一時停止内のボタンも角速度による上下左右の選択とガードでの決定、またはマウスで操作します。開いた直後は「ゲームに戻る」を選択し、現在の選択を青い枠で表示します。基本ボタンは「タイトルへ」「ゲームに戻る」「やり直す」の3つです。「やり直す」はRと同じ `MasterController.ResetMatch()` を呼んで一時停止を閉じ、キャラ・色・固定ステージ・表示方式と接続を保ったまま試合を最初から始めます。ひとり用でもP1・P2両方のQRを表示します。QRは選択・クリックの対象にせず、カード内のガード状態・正面合わせ・再接続の操作は表示しません。スマホ接続中はスマホを優先し、未接続の場合は無線またはUSBリモコンで操作します。
- Yのデバッグ画面は削除しました。対戦・フリーモードの画面分割／1画面はEscの一時停止内で切り替えます。P1/P2のコントローラ・スマホ・未接続状態も一時停止内にだけ表示します。キャラ選択にはP1/P2の見出しを表示せず、準備状態と選択内容を残します。戻るボタンは画面左下の固定アンカーに置きます。
- シングルとフリーモードは `circular_stadium.blend` の円形スタジアム（`circularStadiumStage`、番号2）を使います。対戦は `chambara_stage.blend` の台（番号0）とスタジアム背景を使い、最終決戦は次ラウンドの開始時に `chambara_stage_small.blend` の小さい台へ切り替えます。ステージ選択画面はありません。フリーでは通常の剣・ガード・接触を試せます。移動は円形スタジアムの床の外周（インポートしたモデルから取得）まで可能です。敵・時間制限・得点・場外敗北・ラウンド進行を使わず、接続ポーズで表示方式を切り替えられます。
- 選択パネル内の肖像はモデルの独立したコピー・カメラ・RenderTextureを使います。各パネル右下の「プレビュー」は別の `Screen.Preview` へ進み、決定済みの実キャラクター1体をフィールド上で正面から表示します。剣の姿勢とガードは通常プレイと同じMotion・キーボード入力を使い、時計・攻撃・敵の進行は止めます。対戦1画面モードの対面側の左右反転もプレビューへ適用します。選択枠だけ動かした未決定の値は確定しません。下への方向操作で左下の「もどる」を選び、ガードでキャラ・色・選択枠・準備状態を保持して選択画面へ戻ります。上への方向操作で戻るの選択を解除し、ガード動作を試せます。Escの接続ポーズも利用できます。`MasterController.BeginCharacterPreview(index)` / `EndCharacterPreview()` が実モデルとカメラの表示状態を保存・復元し、入力用のルートは有効のまま保ちます。

UIは2026-10-05の指定により飾りの見出しと操作説明を表示しません。タイトル・選択画面にはゲーム画面と別の白・淡水色の背景を使い、試合中のHUDは背景板を使いません。押すボタン、選択中・確定済みの状態、試合の得点や体力など必要な情報を残します。日本語のフォントは `DuelPresentation.CreateJapaneseFont()` を共通で使用します。

スマホ送信側のテストでは、姿勢角と角速度の異なる軸定義を使って物理的な上下左右の動作からブラウザイベントを作り、6種類の端末姿勢・4方向の画面表示・保存した軸設定で方向を確認します。画面が上向き・左向き・横表示・軸入れ替えの送信値をUnityの実デコーダとキャラ選択画面にも通し、ひとり用・ふたり用の両入力で下振りが赤い色枠、右振りが次のキャラ枠へ進むことを検証します。

EditModeの `MenuControllerInputTests` は360°/秒の厳密なしきい値・端末の姿勢に依存しない上下左右の方向・画面が上向き／左向きのスマホパケット・保存した軸入れ替えを含む送信値の方向・高速入力中の連続移動抑制・低速での即時再受付・元の姿勢へ戻す条件の不在・端末時計による姿勢差分・ガード中の抑制・姿勢更新・短押し／0.5秒長押しの境界・解放時の二重実行抑制・旧リセット番号・再接続を確認します。PlayModeの `GameFlowPlayTests` は起動、接続維持、スマホ・ハードウェア入力での姿勢に依存しない方向判定と低速復帰後の再操作、軸を入れ替えたスマホの実パケットによるベーシックから下への赤い色枠・右への次のキャラ枠の移動、P2からのひとり用選択と開始、ふたりの独立した選択枠、確定前の値の保持、スタートでの確定、各メニューの戻るフォーカスと決定、接続ポーズの全ボタンから戻るへの到達と選択枠、スマホ・USBのP1/P2による全画面での短押し正面合わせ、人数に応じた直接開始、固定ステージ、3つの基本ボタンと表示選択、QRとボタンの非干渉、各モードのやり直しによる試合状態の初期化、一時停止、全キャラクターのプレビュー範囲、装飾・操作案内の不在、フリーモードを確認します。`CHAMBARA_PREVIEW_DIR` を指定すると `CaptureSelectionFlowWhenRequested` が各画面の画像を保存します。

シングルは初回と各区間の到着時に対戦と共通のラウンド・準備・開始演出を表示します。全10区間ともラウンド1.3秒と準備1.2秒の計2.5秒を使い、その後に開始の合図を表示します。開始まで敵の接近・攻撃を止めます。各区間10人をまとめて出現させ、出現順の攻撃役だけが接近します。待機敵は分散した場所からプレイヤーを見ながら少し歩き、ガードしません。攻撃役への切替時に頭上の金色の合図と短い音を出します。全員を倒すと次の区間へ進みます。
